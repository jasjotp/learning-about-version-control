# Learning about Version Control
Author: Jasjot Parmar

Solving merge conflicts takes conscious effort, but I can do it!

The one thing I like most about version control is that it allows you to easily back up and refer back to your changes. Instead of creating multiple files with different versions of the same program, version control allows us to easily refer back and compare to previous versions of the program. 

One thing I dislike about version control is the high attention to detail you must have when collaborating with a lot of people on the same repository, as it is common to run into a lot of merge conflicts when working with a large team, as you have to make sure to constantly pull recent changes to the repo/branch.
